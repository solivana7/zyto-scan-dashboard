# SoliVana ZYTO Scan Dashboard

**Live:** https://scan.solivana.ai — part of the SoliVana Wellness AI suite: instruments that measure and demonstrate how wellness affects biomarkers and everyday wellbeing.

## The problem

Bioenergetic scan reports (ZYTO) arrive as 20-page PDFs packed with 200+ biomarker readings — organs, neurotransmitters, TCM meridians, vertebrae, teeth, emotions. Practitioners cannot quickly read them in a session, and clients leave with a stack of paper they never look at again.

## The approach

This dashboard turns a scan PDF into an interactive, practitioner-facing reading in the browser:

1. **Client-side PDF parsing** — pdf.js extracts the report text in the browser (no scan ever leaves the device), and a dual-format parser handles both the classic ZYTO layout and the newer "Today's Immunity" section format, extracting 222 biomarkers plus emotions, balancers, and services.
2. **Interactive dashboard** — a 3D organ stress map, an emotion wheel, category bars, and a balance score animate the parsed data so patterns are visible at a glance.
3. **Voice-stress DSP** — an optional, experimental voice check runs browser-native digital signal processing (frame-based autocorrelation pitch tracking with median F0) to estimate jitter, shimmer, HNR, and F0 as vocal-biomarker proxies.
4. **LLM interpretation** — Claude (bring-your-own-key, stored only in the practitioner's browser) narrates the patterns in plain language, and a deterministic mock responder keeps the demo fully functional without a key.

## Engineering highlights

- **Dual-format PDF parsers with regex fallback.** Two ZYTO report layouts are supported; the parser runs multiple permissive patterns, dedupes, and filters page-header noise and patient-name lines so identity never reaches the rendering layer.
- **Browser-native DSP pitch tracking.** Frame-based autocorrelation with median-F0 smoothing extracts jitter, shimmer, HNR, and F0 without any audio leaving the device.
- **Name-stripping privacy design.** Parsing happens client-side and the render pipeline never receives the client's name — the dashboard is name-agnostic by construction.
- **FDA-status disclosure language.** Built-in compliance copy: the ZYTO Hand Cradle is FDA-cleared for galvanic skin response measurement; the software output is wellness education, not diagnosis.
- **Synthetic sample data.** The repo ships a clearly labeled synthetic sample client ("Sample Client", balance 72) so every screen can be reviewed without real health data; `generate_dashboard.py` regenerates the standalone dashboard from the same synthetic dataset.

## Stack

- Static HTML/CSS/JS single-page app (`solivana-branded.html`), served by Node 18 + Express (`server.js`). No build step.
- pdf.js for in-browser PDF text extraction.
- Vanilla JS for the 3D organ map, emotion wheel, and trend charts.
- `generate_dashboard.py` (Python 3, stdlib only) renders the standalone `dashboard.html` demo from a synthetic dataset: `python3 generate_dashboard.py --output dashboard.html`.

## Repository contents

- `solivana-branded.html` — the main single-page application (served at `/`).
- `zyto-data.json` — synthetic sample dataset loaded by the app at runtime.
- `generate_dashboard.py` + `dashboard.html` — standalone dashboard generator and its generated output.
- `server.js`, `Procfile`, `railway.json` — minimal Express host for static deploys.

## Compliance

- AI outputs carry a "Generated by SoliVana AI — educational, not diagnostic" label.
- PDF upload requires explicit in-browser consent before parsing.
- Wellness-education disclaimers on every results view; FDA-status language in the footer.
